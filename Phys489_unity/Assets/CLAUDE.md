## Key Physics Concepts

### Universal Multifractal (UM) Parameters
- **H** (0–1): Hurst exponent — controls spectral slope / smoothness. Higher H = smoother.
- **C1** (0–1): Intermittency codimension — controls clustering of extreme events. Higher C1 = spikier.
- **α (alpha)**: Lévy index — multifractality index. α=2 is log-normal; α<2 gives heavier tails.

### Theoretical spectral slope
```
β = 1 + 2H − K(2)
K(2) = C1 / (α−1) · (2^α − 2)        [general Lévy-stable]
     = 2·C1                            [log-normal limit α=2]
```
The Python analysis fits E(l) ∝ l^(−β) in log-log space over spherical harmonic degrees to verify scale invariance.

## FIF Cascade Architecture

Both cloud and albedo fields are generated by the **FFT-based Fractionally Integrated Flux (FIF)** pipeline in `FIFGenerator.compute`. This replaced the earlier per-pixel spectral-wave approach (J=16 plane waves per octave), which produced visible line artifacts and incorrect β for low-H parameters.

### FIF Pipeline (per realization)

```
GenerateSpectrum  →  BaseSpectrumBuffer   (once per realization / param change)
PhaseShift        →  SpectrumBuffer       (per frame, copies + advects cloud field)
IFFTRow           →  SpectrumBuffer       (in-place 1D IFFT, rows)
IFFTCol           →  SpectrumBuffer       (in-place 1D IFFT, columns)
ExtractField      →  LogFieldTex + PhysicsData
```

The cascade and terrain shaders then sample `LogFieldTex` for visualization only.

### GenerateSpectrum kernel
For each Fourier mode (kx, ky):
- Amplitude: `CMS_sample × (C1·ln²)^(1/α) × |k|^{−(H+1)}`
- The `|k|^{−(H+1)}` weighting accounts for the 2D mode density (∝ |k|) and gives E(l) ∝ l^{−(1+2H)}.
- Intermittency (C1, α) is encoded in the CMS α-stable amplitude distribution.
- Phase: independent uniform random from PCG hash.

### IFFT (IFFTRow + IFFTCol)
- Radix-2 Cooley-Tukey DIT, 10 stages for N=1024.
- Shared memory: `groupshared float2 gs_data[1024]` (8 KB, within DX11 32 KB limit).
- Bit-reversal via `reversebits()` HLSL intrinsic.
- No 1/N normalization — the `|k|^{−(H+1)}` weighting already gives the right field magnitude.
- Dispatch: `(N, 1, 1)` groups × `[numthreads(1024, 1, 1)]`.

### PhaseShift kernel (cloud animation)
Simulates advection (Taylor frozen-turbulence hypothesis):
```
coeff(k, t) = coeff(k, 0) × exp(i · 2π · (kx·vx + ky·vy) · t)
```
`WindVelocity` (inspector, UV-space cycles/second) controls cloud drift speed and direction.
For static albedo, PhaseShift is called with `Time=0` (plain copy).

### ExtractField kernel
```
field_val = exp(clamp(Re(IFFT_output), −20, 20))
```
Writes to both `LogFieldTex` (RFloat RenderTexture, sampled by visualization shaders) and `PhysicsData` (ComputeBuffer, read by DataExporter for CSV export).

## Noise Primitives (NoiseUtils.cginc)

Included only by `FIFGenerator.compute`.

- **`hash(float3)`**: PCG-3D hash. Ref: Jarzynski & Olano (2020).
- **`levyStable(float3 id, float alpha)`**: CMS symmetric α-stable generator.
  - V ~ Uniform(−π/2, π/2), W ~ Exponential(1)
  - X = sin(α·V) / cos(V)^(1/α) × (cos((1−α)·V) / W)^((1−α)/α)
  - Ref: Chambers, Mallows & Stuck (1976), JASA 71(354):340–344.

## Visualization Shaders

### CascadeShader.compute (cloud)
- Samples `FIFFieldTex` (cloud log-field RT) for the dressed flux.
- Log tone-maps: `displayValue = saturate(log(1 + field) / log(1 + 3))`
- Composites cloud layer over `AlbedoTex` (terrain color RT) using cloud alpha.
- No physics computation — visualization only.

### TerrainShader.compute (albedo)
- Samples `AlbedoFIFFieldTex` (albedo log-field RT).
- Same log tone-map, applies terrain color gradient LUT.
- Output `_albedoRT` is read by CascadeShader as `AlbedoTex`.
- No physics computation — visualization only.

## Unity Architecture (SimulationController.cs)

**Buffers and textures:**
- `_cloudBaseSpectrumBuffer` / `_cloudSpectrumBuffer` — complex float2 N×N, persistent base + working
- `_albedoBaseSpectrumBuffer` / `_albedoSpectrumBuffer` — same for albedo
- `_cloudLogFieldRT` / `_albedoLogFieldRT` — RFloat 1024×1024, output of ExtractField
- `_albedoRT` — ARGB32 1024×1024, coloured terrain (output of TerrainShader)
- `PhysicsBuffer` — shared float[N²] for CSV export (overwritten per FIF dispatch)

**Per-frame flow (cloud):**
1. If cloud UM params changed → `RegenerateCloudBase()` (new random seed)
2. If albedo UM params changed → `DispatchAlbedoFIF()` (new random seed + terrain visualize)
3. `PhaseShift` → `IFFTRow` → `IFFTCol` → `ExtractField` → `_cloudLogFieldRT`
4. `CascadeShader`: composite cloud + albedo → `RenderTexture` (display)

**Snapshot independence:** Each snapshot calls `GenerateSpectrum` with a fresh `Random.Range(0, 1000000)` seed. Wave independence comes from the random CMS amplitudes and phases, not spatial offsets.

## Current Limitations / Known Issues

- **Space-Time Anisotropy not implemented**: Isotropic scaling only. GSI anisotropy (Lovejoy) is the next major feature. Extension path: replace `|k| = sqrt(kx²+ky²)` with `|G⁻¹k|` in `GenerateSpectrum`, where G is the GSI generator matrix. Only that kernel needs to change.

- **K(q) / Intermittency underestimated**: The FIF is an *additive* linear superposition of Fourier modes. With ~10⁶ modes summed, the CLT drives the log-field toward Gaussian regardless of the injected α-stable distribution. Result: measured C1 ≈ 0.05–0.08 vs target 0.10–0.12. The spectral slope β is unaffected. A *multiplicative* FIF (iterated cascade in Fourier space) would be needed to recover full K(q) accuracy, but is significantly more complex.

- **2D equirectangular noise**: The FIF operates on the flat pixel grid, not on the sphere surface. Near the poles, the physical spatial scale per pixel is compressed. The Python analysis (pyshtools) accounts for this with proper latitude weighting, so β measurements remain valid.

- **Spectral fitting range**: `main.py` uses l ∈ [8, 60]; `verify_albedo.py` uses l ∈ [4, 80].

- **Texture resolution hardcoded**: `N = 1024` and `LOG2N = 10` are compile-time constants in `FIFGenerator.compute`. Changing `textureResolution` in the inspector also requires updating these shader constants.
